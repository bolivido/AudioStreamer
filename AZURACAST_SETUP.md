# 🚀 AzuraCast Setup Guide

## 🎯 **What is AzuraCast?**

AzuraCast is a **modern, self-hosted radio station management system** that provides everything you need to run a professional radio station.

## ✨ **Features You'll Get:**

- **🎵 Music Library Management** - Upload, organize, and manage your music
- **📻 Live Streaming** - Multiple streaming backends (Icecast, Shoutcast)
- **📅 Playlist Scheduling** - Auto-play music with custom schedules
- **👥 DJ Management** - Multiple user accounts and permissions
- **📊 Analytics** - Listener statistics and performance metrics
- **🌐 Web Interface** - Easy-to-use management dashboard
- **📱 Mobile Apps** - Manage your station from anywhere

## 🚀 **Deployment on Railway:**

### **1. Automatic Deployment:**
- Railway will use the official AzuraCast Docker image
- No more complex manual configuration
- Professional setup out of the box

### **2. Access Your Station:**
- **Web Interface**: `https://your-app.railway.app`
- **Stream URL**: `https://your-app.railway.app:8000/`
- **Admin Login**: `admin@audiostreamer.com` / `admin123`

## 🎵 **Getting Started:**

### **1. First Login:**
1. Go to your Railway app URL
2. Login with: `admin@audiostreamer.com` / `admin123`
3. Complete the setup wizard

### **2. Create Your Station:**
1. Click "Create New Station"
2. Name: "AudioStreamer Radio"
3. Description: "Custom radio station with metadata"
4. Genre: "Custom"

### **3. Upload Music:**
1. Go to "Music Files" in your station
2. Drag & drop MP3 files
3. Add metadata (artist, title, album)
4. Create playlists

### **4. Start Streaming:**
1. Go to "Streamers" in your station
2. Enable the default streamer
3. Your station is now live!

## 🔧 **Configuration:**

### **Streaming Settings:**
- **Port**: 8000 (default)
- **Format**: MP3, AAC, OGG
- **Bitrate**: 128k (adjustable)
- **Metadata**: Real-time song information

### **Playlist Settings:**
- **Auto-play**: Continuous music rotation
- **Scheduling**: Custom time-based playlists
- **Crossfade**: Smooth transitions between songs

## 📱 **Management Features:**

### **Web Dashboard:**
- **Station Overview** - Current song, listeners, status
- **Music Library** - Upload, organize, search music

### **User Management:**
